ATS - HOW TO START (WINDOWS)
============================

1. Open PowerShell in your project folder (the folder with run.py).

2. In TERMINAL 1, run:

.\.venv\Scripts\python.exe run.py

Leave this terminal open.

3. Open your browser:

http://127.0.0.1:8000

4. Click Sync. Wait until it says SUCCEEDED.
   If the background worker is running, click Stop before Sync.

5. Click Start if you want automatic daily updates.

6. To stop:
   Click Stop in the dashboard.
   Wait for any running job to finish.
   Press Ctrl+C in TERMINAL 1.

NEXT TIME: Repeat steps 1-5. No reinstall needed.

OPTIONAL: SAMPLE PAPER REPLAY
----------------------------
Open TERMINAL 2 in the same project folder.
Keep TERMINAL 1 running. In TERMINAL 2, run:

.\.venv\Scripts\python.exe scripts/replay_paper.py --quotes data/paper_quotes_example.csv --orders data/paper_orders_example.csv

This is a sample replay, separate from the dashboard paper account.
Terminal 2 is not needed for normal dashboard use.
